Claude Code Plugin

Coding lessons that run inside Claude Code — and ship verified work.

ACC turns a Claude Code session into a coding tutor. You install the framework, you install (or write) a course plugin, and the conductor walks the learner chapter by chapter: it implements each chapter until its tests pass, explains the code with an HTML artifact, and closes the lesson with an end-to-end test and a summary page.

How it works

ACC is the engine. Courses are content plugins. A lesson is a topic plus its docs, split into chapters that are defined by tests. The agent implements each chapter, explains it with an HTML artifact, and proves the whole feature with an end-to-end test and a summary.

Three pieces, clearly separated

ACC ships no lesson content of its own. That separation is the design — the framework stays small and reusable; courses own their domain.

Framework

ACC

This plugin. MCP server, conductor agent, authoring skills, artifact conventions, the four probe interpreters, and the workspace lifecycle. Domain-agnostic.

Content

Course plugin

A separate Claude Code plugin that declares accContent: lessons (docs, chapters, tests, reference solution), prerequisite probes, configurable paths. ACC discovers it at runtime.

Experience

Lesson

An end-to-end run: the agent implements each chapter until its tests pass, explains it with an HTML artifact, pauses for questions, then runs the e2e test and writes a summary.

The course: build agents with the Claude Agent SDK

acc-claude-sdk is the first course on the v0.3 chapter model. Lesson 1 builds the smallest useful agent in TypeScript; later lessons add sessions, hooks, and subagents. Everything the agent writes is explained in an HTML artifact you keep.

Claude Agent SDK · TypeScript · v0.3

acc-claude-sdk

Lesson 1, Your first agent, in three chapters, each defined by its tests:

  1. Run a query and read the result. query() returns an async iterable of typed messages; the result message is the contract.
  2. Give the agent a custom in-process tool. A Zod shape plus an async handler, served by createSdkMcpServer() and addressed as mcp__notes__add_note.
  3. Wrap it in a tiny CLI. Inject query() and the output streams so the CLI is testable offline; the result message drives the summary line.

Unit tests run offline against a fake message stream. The end-to-end test runs the real agent and needs ANTHROPIC_API_KEY. Every chapter ends with an artifact; the lesson ends with a summary page of the most important learnings.

/plugin install acc-claude-sdk@contract-hero then /acc-claude-sdk:start

Bring your own

Your course

Any plugin that declares accContent is a course. Scaffold one — plugin.json, probes, paths, and an empty lessons tree — then add lessons from a topic and its docs. The lesson creator curates the docs, plans the chapters, writes the tests and the reference solution, and validates the lesson with a learner sub-agent.

/agentic-community-college:create-course

How a chapter runs

There are no output modes. The agent writes the code; you read, ask, and confirm. ACC recommends the Concise Claude Code output style and offers to set it when a lesson starts, because the learning content lives in the artifacts, not in the chat.

1

Tell

"Chapter N of M": what gets implemented, the key idea, and which tests define done.

2

Implement until the tests pass

The conductor reads the lesson's docs snapshot and the chapter's tests, edits only the chapter's expected files, and runs the chapter's verification command until it is green.

3

Explain with an artifact

One self-contained HTML page per chapter: what was built, a diagram of how it works, the key snippets taken verbatim from the workspace, and the tests that prove it.

4

Verify

The MCP runs the official gate, advances the chapter cursor, and records the artifact. A failed gate goes back to you; it is never retried silently.

5

Pause

Continue, ask questions, or stop here. Never more than one chapter per turn. After the last chapter the conductor runs the end-to-end test and writes the summary page.

Quick start

ACC is a Claude Code plugin. Install it, install a course alongside it, and start a lesson.

1

Install ACC

From any Claude Code session:

/plugin marketplace add contract-hero/plugin-marketplace
/plugin install agentic-community-college@contract-hero
2

Install the course

Any plugin that declares accContent works. acc-claude-sdk is the course built for the v0.3 model (the previous courses are pending migration):

/plugin install acc-claude-sdk@contract-hero
3

Start a lesson

Run the course's start command. ACC lists the catalog, offers the Concise output style, you pick a lesson, and the conductor takes over chapter by chapter.

/acc-claude-sdk:start
4

Author your own

To teach a new domain, scaffold a course plugin and add lessons from a topic and its docs:

/agentic-community-college:create-course
/agentic-community-college:create-lesson
Note. ACC pairs with the toolkit@contract-hero plugin for post-lesson publishing (publish-html on the summary artifact). It is optional: lessons and artifacts work without it.
